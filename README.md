# java-lotto-precourse


# 🎯 로또 발매기


## 🚀 학습 목표


관련 함수를 묶어 클래스를 만들고, 객체들이 협력하여 하나의 큰 기능을 수행하도록 구현합니다.

클래스와 함수에 대한 단위 테스트를 통해 의도한 대로 정확하게 작동하는 영역을 확보합니다.

Java Enum을 적용하여 로또 등수와 상금을 관리합니다.

객체 지향 생활 수칙 및 프로그래밍 요구 사항을 준수하며 코드를 구현합니다.


## ✨ 기능 요구 사항


### 1. 구입 금액 입력 및 로또 발행

   
사용자로부터 로또 구입 금액을 입력받습니다.

구입 금액은 숫자여야 하며, 1,000원 단위여야 합니다.

구입 금액은 0보다 커야 합니다.

위의 조건을 만족하지 않을 경우, [ERROR] 메시지와 함께 IllegalArgumentException을 발생시키고 재입력을 받습니다.

구입 금액에 해당하는 수량만큼 로또를 발행하고 발행 수량을 출력합니다. (로또 1장의 가격은 1,000원)

발행된 로또 번호 6개를 오름차순으로 정렬하여 출력합니다.

로또 번호는 1~45 사이의 중복되지 않는 6개의 숫자여야 합니다.


### 2. 당첨 번호 및 보너스 번호 입력


사용자로부터 당첨 번호 6개를 입력받습니다.

입력은 쉼표(,)를 기준으로 구분됩니다.

당첨 번호는 1~45 사이의 숫자여야 하며, 중복되지 않아야 합니다.

입력된 값 중 숫자가 아닌 경우, 쉼표 사이에 빈 값이 있는 경우 등은 예외 처리합니다.

위의 조건을 만족하지 않을 경우, [ERROR] 메시지와 함께 IllegalArgumentException을 발생시키고 재입력을 받습니다.

사용자로부터 보너스 번호 1개를 입력받습니다.

보너스 번호는 숫자여야 합니다.

보너스 번호는 1~45 사이의 숫자여야 합니다.

보너스 번호는 당첨 번호와 중복될 수 없습니다.

위의 조건을 만족하지 않을 경우, [ERROR] 메시지와 함께 IllegalArgumentException을 발생시키고 재입력을 받습니다.


### 3. 당첨 확인 및 결과 출력


사용자가 구매한 로또 번호와 당첨 번호, 보너스 번호를 비교하여 당첨 내역을 계산합니다.

| 등수 | 일치 조건 | 상금 | 메시지 |
 
 
 | 1등 | 6개 번호 일치 | 2,000,000,000원 | 6개 일치 (2,000,000,000원) |
 
 | 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 | 5개 일치, 보너스 볼 일치 (30,000,000원) |
 
 | 3등 | 5개 번호 일치 | 1,500,000원 | 5개 일치 (1,500,000원) | 
 
 | 4등 | 4개 번호 일치 | 50,000원 | 4개 일치 (50,000원) | 
 
 | 5등 | 3개 번호 일치 | 5,000원 | 3개 일치 (5,000원) |
 

당첨 통계를 위 표의 순서대로 출력합니다. (5등부터 1등 순)

총 수익률을 계산하여 출력합니다.

수익률은 (총 당첨 금액 / 구입 금액) * 100으로 계산합니다.

수익률은 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시합니다.

## ✅ 프로그래밍 요구 사항 준수

indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현 (2까지만 허용)

3항 연산자를 쓰지 않음

함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 (15라인 이하)

Java Enum(LottoEnum)을 적용하여 로또 등수 구현

JUnit 5와 AssertJ를 이용한 단위 테스트 작성 (UI 로직 제외)


## 🛠️ 구현할 기능 목록

1. LottoCount 클래스 (**로또 구입 금액에 해당하는 수량 관리**)

2. Lotto 클래스 (**로또 번호들에 대한 기능**)

3. Splitter 클래스 (**입력 문자열 처리**)

4. Bonus 클래스 (**보너스 번호 관련 기능**)

5. Input 및 Output 클래스 (**입출력**)

6. Selection 클래스 (**랜덤 로또 발행**)

7. Result 클래스 (**로또 당첨 결과**)

8. Run 클래스 (**프로그램 실행 흐름 제어**)
